# Logic prototype

Build one self-contained HTML/CSS/JS file that opens without a server. State the design question visibly. Keep the model in a pure reducer, state machine or small module, separate from DOM code. The page calls the model and renders full relevant state in domain language after every action.

Provide free-play actions and tabbed guided walkthroughs: happy path, awkward edge case and an illegal transition. Each walkthrough resets to known state and its steps perform real actions. Keep state in memory, use restrained presentation and make the model's response visible. Record the verdict and the source under the session; lift only agreed decision-rich logic into subsequent authorized production work.
